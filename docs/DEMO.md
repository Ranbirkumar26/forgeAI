# Demo Script

1. Start the API and web app.
2. Paste the absolute path to `examples/sample-repo`.
3. Click `Index Repo`.
4. Click `Start Run`.
5. Point out that Coder generated a patch artifact and paused before writing.
6. Click `Approve`.
7. Watch the timeline complete through Testing, Vision, Security, Review, Docs, Deployment, and Memory.
8. Open the artifact list and show the prepared patch, visual diff path, review notes, changelog, and LinkedIn draft.

The strongest recruiter angle is that ForgeAI is not "chat with docs." It is a control plane: graph orchestration, approvals, RAG, memory, visual inspection, observability, and deploy plugin boundaries.
